# Alsalaam Primary & Secondary School — Website + CMS

Full-stack project: React/Vite/Tailwind frontend + Node/Express/MongoDB backend + Admin Dashboard.

## Structure
- frontend/ — public website + admin dashboard (React)
- backend/ — REST API (Express + MongoDB + JWT + Cloudinary + email)

## Setup
See frontend/.env.example and backend/.env.example for required environment variables
(MongoDB URI, JWT secret, Cloudinary keys, SMTP credentials).

Backend: cd backend && npm install && npm run dev
Frontend: cd frontend && npm install && npm run dev
